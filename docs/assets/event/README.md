# Dev Days Cape Town event assets

These assets were downloaded from the public Cape Town MS Developer User Group
websites on 17 September 2026 for offline presentation use.

Primary sources:

- <https://cptmsdug.dev/dev-days-2026.html>
- <https://cptmsdug.dev/>

## Branding

| File | Use |
|---|---|
| `branding/devdays2026hero.png` | Locked full-bleed background for the keynote welcome slide |
| `branding/cptmsdug.png` | Cape Town MS Developer User Group navigation/logo lockup |
| `branding/cptmsdugcolor.png` | Square color user-group mark |

## Sponsors and venue

| File | Public role |
|---|---|
| `sponsors/microsoftlogo.png` | Microsoft, headline sponsor |
| `sponsors/bbd.png` | BBD, venue sponsor |
| `venue/bbd-cpt1.png` | BBD Cape Town venue photograph |

The source Microsoft logo was AVIF and was converted to PNG for PowerPoint
compatibility. The event site says more sponsors may be added, so this folder
must not be treated as the final sponsor lock.
