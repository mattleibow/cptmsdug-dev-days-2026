## Mobile continuity

- [About remote control of Copilot CLI sessions](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/about-remote-control)
- [Steering a Copilot CLI session from another device](https://docs.github.com/en/copilot/how-tos/copilot-cli/steer-remotely)

Remote control does not move execution to the phone. The original machine must
remain online, and commands and file operations continue there.

## Extensibility

- [About Copilot plugins](https://docs.github.com/en/copilot/concepts/agents/about-plugins)

Support for instructions, custom agents, skills, MCP servers, hooks, plugins,
Canvas extensions, and automations differs across Copilot surfaces. Avoid
presenting one client-specific capability as universally available.
