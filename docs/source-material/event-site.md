# Dev Days Cape Town 2026 event-site facts

Source: <https://cptmsdug.dev/dev-days-2026.html>  
Retrieved: 17 September 2026

The event website is the local source of truth for public event details. The
organizer confirmed the published speaker lineup and session order for
presentation use on 17 September 2026.

## Event identity

- **Public name:** Dev Days Cape Town 2026
- **Descriptor:** GitHub Copilot Community Event
- **Date:** 3 October 2026
- **Venue:** BBD Cape Town, Century City
- **Format:** Full-day, in-person-only; no virtual or livestream option
- **Audience:** Open to all developers
- **Organizer:** Cape Town MS Dev User Group
- **Focus:** Practical GitHub Copilot workflows, hands-on activities, App and
  CLI workshops, industry speakers, and community networking
